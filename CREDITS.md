# Credits

## Sounds

The game's four sounds are placeholders made in code by `src/engine/services/audio/placeholder-sounds.ts` (a noise burst for the paper rustle, a falling low sine for the thump, a small bell for the chime, a loop of random pops for the flame). They contain no recordings and no third-party material, so nothing is owed to anyone. The team intends them to be CC0 1.0; the repository has no licence file yet, so confirm that choice (and the project's own licence) before submission. They exist so the audio works before the team's sounds arrive.

| Sound | Made by | Licence |
|---|---|---|
| Paper rustle, thump, chime, flame crackle | `placeholder-sounds.ts` (this project) | Made by the project; intended CC0 1.0 (to confirm) |

When real sounds replace them, add a row for each file here: what it is, who made it, where it came from (a link), and its licence (CC0 or another that allows use in a game). Do not add a file whose licence is not recorded here.
